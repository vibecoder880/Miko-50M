# Miko-50M: dataset-v0.2 built, Stage-2 Gate D pass, 38M pretraining running

## What happened

Third ak-cook session on the Miko-50M plan (milestones M2->M3):

1. **dataset-v0.2 (48M tokens)** — code source added to
   scripts/fetch_corpus.py: codeparrot/codeparrot-clean with per-file
   permissive-license whitelist (MIT/Apache/BSD/...), autogenerated skip,
   license_counts in manifests. the-stack-smol turned out gated;
   code_search_net hub URIs broken (needs namespace) — codeparrot-clean
   won on availability + license metadata. Fetched vi-wiki 7000 docs +
   en-wiki 2100 + 15K Python files, trimmed code file to 57MB to approach
   the plan §11 mixture. tools/pack_dataset.py now reports per-source
   docs/tokens/share (mixture manifest). Result: 48.0M tokens, vi 38.9% /
   code 36.9% / en 24.2% (target 50/20/25/5 — vi still under, note for
   v0.3). Tokenizer: 16K byte-level BPE reached exactly.

2. **Stage-2 probe (Gate C + D)** — Miko Tiny 2.3M, 4000 steps / 2.05M
   tokens: train 18.8→1.69, val monotonic 7.92→7.57 (Gate C PASS on v0.2).
   Eval vs Stage-1 same items: vi_basic 0.00→0.06 (**Gate D PASS**),
   code_basic 0.08→0.25, chat_basic 0.12→0.00 (v0.1 had hand-seeded chat
   sentences; honest trade). Val ppl 1931 on the harder corpus.

3. **38M real pretraining running** — scripts/train_38m.sh (nohup, nice 10,
   adafactor, checkpoint 500, --resume auto). Step 50 at 419 tok/s →
   ~41M-token budget ≈ 27h wall (benchmark's 58 tok/s reading was
   pessimistic; long-run average is the trustworthy number).

## Mistakes caught

- `git add -A` staged 190MB of corpus text (cleaned_v2 not covered by the
  cleaned/ ignore pattern) — removed from index, amended, gc'd (.git 528KB).
- Mixture first pass was code-heavy (70% by tokens) because codeparrot
  files average ~9KB; rebalanced by fetching more vi/en and trimming code.

## Decision

- Benchmark tok/s on this box varies 58–419 with load; treat RSS numbers
  as the decision-relevant ones and long-run CSV averages for throughput.
- Run the 38M at nice 10 so the shared box stays interactive; resume is
  checkpoint-safe every 500 steps.

## Next steps

1. Monitor logs/train_38m.csv; after ~5K steps run tools/evaluate.py on

2. v0.3 dataset: more Vietnamese text (OSCAR/Vi texts) + JS/Go/SQL code
   to reach the 50/20/25/5 mixture.
